# Agentic BI Workshop Instructions

Use these instructions when working in this workshop folder.

- Treat `../03-Demo-Project` as read-only.
- Create hands-on work under `06-agentic-bi-workshop/work/`.
- Use the Power BI Authoring MCP server for semantic model changes: tables, columns, relationships, measures, DAX, descriptions, and validation.
- Use the `powerbi-report-authoring` skill for PBIR report changes: pages, visuals, filters, themes, formatting, validation, Desktop reloads, and screenshots.
- Do not edit report layout through the semantic modeling MCP server.
- Do not edit semantic model objects by ad hoc string replacement when MCP tools are available.
- Save Power BI Desktop before editing project files externally.
- After external edits, reload or apply changes in Power BI Desktop before judging the result.
- Prefer small, reviewable changes and explain which files changed.
- Validate DAX and PBIR schemas before declaring the lab complete.
